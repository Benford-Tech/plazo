Le formulaire de réservation de votre parking d'aéroport, relié à Plazo Pro.

== Description ==

Les clients choisissent leurs dates sur votre site : le formulaire montre si le parking a de la place et le prix de votre grille, puis la réservation arrive tout de suite dans le planning de Plazo Pro, au canal « Site du parking ». Le client paie au parking.

== Installation ==

1. Extensions › Ajouter › Téléverser l'extension : choisissez plazo.zip, puis Activer.
2. Réglages › Plazo : collez la clé de votre parking (Plazo Pro, Parking › Réglages › Site du parking).
3. Collez [plazo_reservation] dans la page « Réserver » de votre site.
